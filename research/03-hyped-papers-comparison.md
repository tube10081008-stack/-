# 3. 현시점(2026-08) 최고 화제 논문 3편과 비교

## 3.1 선정 방식

2장에서 도출한 세 조직의 **공통 병목 = 장기 상호작용에서의 기억/적응**에 정확히 대응하면서,
2025년 말~2026년 상반기에 커뮤니티 화제성(공식 리서치 블로그 발표, HF Papers 상위, 다수의 후속·재현 연구)이
확인되는 논문을 축별로 하나씩 골랐다. 세 논문은 **기억을 어디에 두는가**로 서로 직교한다.

| 축 | 기억의 소재 | 선정 논문 |
|---|---|---|
| ① 파라메트릭 | 가중치/아키텍처 내부 | **Nested Learning / HOPE** |
| ② 논파라메트릭 | 외부 메모리 모듈(코드·스키마) | **ALMA** |

## 3.2 논문 개요

### (P1) Nested Learning: The Illusion of Deep Learning Architectures — Google Research (2025, NeurIPS)
- 계보: *Titans: Learning to Memorize at Test Time* (2025)의 후속. 저자군 공통(Ali Behrouz 외, Google Research).
- 핵심 주장: 모델을 **서로 다른 갱신 주기를 갖는 중첩 최적화 문제들의 집합**으로 재해석한다.
  "아키텍처"와 "학습 알고리즘"의 구분이 사실은 환상(illusion)이며 동일한 것의 다른 층위다.
- 제안 구조 **HOPE**: Titans의 자기수정(self-modifying) 변형 + **Continuum Memory System(CMS)**.
  단기/장기라는 2분법 대신 **연속적인 갱신 주파수 스펙트럼** 위에 메모리 모듈을 배치한다.
- 결과: 언어모델링·상식추론에서 Titans/Samba/표준 트랜스포머 상회, 장문 검색과 **지속 학습(continual learning)** 에서 강건.
- 한계: 공식 구현·배포 경로 없음. 커뮤니티 재현만 존재 → **"방향"이지 "제품"이 아니다.**

### (P2) Learning to Continually Learn via Meta-learning Agentic Memory Designs (ALMA) — arXiv:2602.07755 (2026-02)
- 저자: Yiming Xiong, Shengran Hu, **Jeff Clune** (ADAS/오픈엔디드 계열).
- 문제 제기: 파운데이션 모델은 **stateless**이고, 이를 보완하는 메모리 모듈은 대부분 **사람이 손으로 설계한 고정 구조**다.
  실세계의 다양성·비정상성(non-stationarity)에 적응하지 못한다.
- 제안: **Meta Agent가 메모리 설계 자체를 실행 가능한 코드로 탐색**한다. DB 스키마, 검색 규칙, 갱신 규칙까지
  오픈엔디드하게 생성 — 원리적으로 임의의 메모리 설계를 발견할 수 있다.
- 결과: 4개 순차적 의사결정 도메인 전부에서 SOTA 수작업 메모리 설계를 상회(효과성·효율성 모두).
- 한계: 탐색 비용이 크고, 검증 도메인이 **과업(task) 성공률** 중심 — "재미"나 "서사"는 보상에 없다.

### (P3) Controllable Memory Usage: Balancing Anchoring and Innovation in Long-Term Human-Agent Interaction (SteeM) — arXiv:2601.05107 (2026-01)
- 저자: Muzhao Tian 외, 푸단대.
- 문제 제기: 현행 시스템의 기억 사용은 **all-or-nothing**이다.
  - 전부 넣으면 **Memory Anchoring** — 에이전트가 과거에 갇혀 같은 말·같은 전개를 반복한다.
  - 전부 빼면 활용 부족 — 관계와 맥락이 소실된다.
- 제안: **기억 의존도(memory dependence)를 행동 지표로 정량화**하고, 사용자가 이를 실시간 조절하는
  **SteeM(Steerable Memory Agent)** — fresh-start(혁신 촉진) ↔ high-fidelity(이력 충실) 사이의 연속 다이얼.
- 결과: 기억 의존도를 **명시적·제어 가능한 차원**으로 다룰 수 있음을 실증.
- 한계: 다이얼을 **누가/언제** 돌릴지는 사람에게 떠넘긴다. 최적값 δ*의 자동 결정·시간적 변화는 미해결.

## 3.3 정면 비교

| 비교축 | P1 HOPE (Nested Learning) | P2 ALMA | P3 SteeM |
|---|---|---|---|
| 기억의 소재 | 가중치 (다중 시간스케일) | 외부 메모리 (코드로 표현된 스키마) | 컨텍스트 주입 강도 |
| 적응 주체 | 모델 자신 (self-modifying) | Meta Agent (설계 탐색) | **사용자** |
| 시간 스케일 | 연속 스펙트럼 (CMS) | 과업 시퀀스 단위 | 턴/세션 단위 |
| 망각을 다루는 법 | 주파수 분리로 catastrophic forgetting 완화 | 메모리 설계가 무엇을 버릴지 학습 | 의존도를 낮춰 **의도적으로** 무시 |
| 최적화 목표 | perplexity, 장문 검색, CL 벤치마크 | 과업 성공률·효율 | 앵커링/혁신 균형(행동 지표) |
| 검증 도메인 | 언어모델링·추론 | 순차적 의사결정 4종 | 장기 인간-에이전트 상호작용 |
| 배포 준비도 | **낮음** (공식 구현 없음) | 중간 (탐색 비용 큼) | **높음** (기존 스택 위에 얹기 쉬움) |
| 페르소나 서사 적용성 | 캐릭터 **정체성 항상성**에 직결 | 세계관·관계 **상태 스키마 자동 설계** | **매너리즘 탈출** 다이얼 |
| 대표적 실패 모드 | 정체성이 느리게 표류(persona drift) | 재미 없는 최적해로 수렴 | 사용자가 다이얼을 안 돌림 |

## 3.4 세 논문을 겹쳐 놓았을 때 드러나는 공백

1. **셋 다 "정확한 회상"을 좋은 것으로 가정한다.** 그러나 스토리텔링에서 완벽한 기억은
   *예측 가능성*을 만들고, 예측 가능성은 이탈을 만든다. P3만이 이 긴장을 인지했으나
   해법을 **사용자의 수동 조작**에 위임했다.
2. **셋 다 서사 구조(narrative structure)를 상태로 갖지 않는다.** 미해결 복선, 관계 단계,
   갈등 강도, 아크 위치 같은 변수는 어떤 메모리 스키마에도 명시되어 있지 않다.
   ALMA가 원리적으로 발견할 수는 있으나, 보상이 과업 성공률이면 결코 발견하지 않는다.
3. **셋 다 단일 저자(single-author) 서사를 가정한다.** 실제 페르소나 플랫폼은
   캐릭터 제작자 · 플레이 유저 · 모델의 **3자 공동저작**이다. 기억의 소유권과
   정규성(canon) 충돌은 정의조차 되어 있지 않다.
4. **평가 지표가 산업 지표와 단절되어 있다.** 논문은 perplexity/성공률을,
   제품은 D7 리텐션/일 체류시간을 본다. 둘을 잇는 중간 지표가 없다.

→ 4장(논문 본문)은 이 네 공백을 정면으로 다룬다.
